# Plan: executor v0.6

Date: 2026-07-16 · Cap: 2-3 days total for v0.6 + grant draft, then maintenance mode.

## Goal

Add a minimal, clearly-isolated order execution module with default builder attribution, so the toolkit ecosystem has a demo-able execution path for the Builder Grant application — without breaking the core's zero-dependency / read-only / no-keys promise.

## Design decision

`executor/` is a **separate sub-package** with its own `package.json` and dependencies (`@polymarket/clob-client-v2`, `@ethersproject/wallet`). The root package stays zero-dependency and never imports from `executor/`. Security posture is documented: core = read-only no keys; executor = opt-in, needs private key + CLOB API creds.

Pattern source: prediction-trader `src/utils/clobV2Orders.ts` + `orderArgsV2.ts` (dry-run verified ENABLED, 2026-07-15).

## Sub-tasks

1. `executor/package.json` + `executor/tsconfig.json` — isolated deps, own `test`/`typecheck` scripts.
2. `executor/src/env.ts` — credential loading from env (PRIVATE_KEY, CLOB API key/secret/passphrase, funder, signature type), validation, no defaults for secrets.
3. `executor/src/client.ts` — `createExecutorClient()`: ClobClientV2 with `builderConfig` resolved via core `src/builder.ts` (default / env override / opt-out preserved).
4. `executor/src/orders.ts` — `buildLimitOrder()` (pure, testable) + `postLimitOrder()` (GTC/GTD) + `cancelOrder()`. **Dry-run by default**: `EXECUTOR_LIVE=1` required for any network mutation; notional guard `EXECUTOR_MAX_USD` (default $10).
5. `executor/src/index.ts` — public exports.
6. `executor/tests/*.test.ts` — unit tests for order building, builder-code resolution paths (default/override/opt-out/malformed), dry-run guard, notional guard. No network.
7. `executor/examples/dry-run.ts` — prints exact V2 order payload incl. builderCode without posting.
8. Docs: `docs/executor.md` (setup, security model, dry-run→live ladder, builder attribution disclosure), README section (both languages), CHANGELOG, version bump 0.5.0 → 0.6.0.

## Acceptance

- Root `npm test` + `npm run typecheck` unchanged and green (core untouched except README/docs).
- `executor/` own typecheck + tests green.
- Dry-run example prints payload with resolved builderCode, honors opt-out.
- No secrets anywhere in repo; `.env` ignored.

## Out of scope / gates

- Pushing branch / release / npm publish → Leo public-publish gate.
- Real order posting → Leo funds gate (not needed for v0.6 acceptance).
- Grant submission → Leo gate; this plan only covers the draft.
- Deposit-wallet (sig_type=3) path → Phase 2, not v0.6.
